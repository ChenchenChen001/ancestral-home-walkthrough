# 祖宅 · 空间漫游

基于真实采集的高斯泼溅数据构建的完整精度静态网页。

站点地址：https://chenchenchen001.github.io/ancestral-home-walkthrough/

## 操作

点击「走进祖宅」后用 WASD 或方向键行走，拖动画面环顾。Shift 加速，飞行模式使用 Q/E 升降，H 返回院前。手机提供触屏方向按钮。

设置支持画质、视高、步速和两点实测尺度校准。原始工程未提供可靠的长度单位，默认比例只是预览估计，必须输入已知实测距离后才能按真实米制漫游；校准保存在当前浏览器中。

## 数据与运行

- 62 个分块，6 级 LOD，25,077,467 个原始高斯点；随视点流式加载。
- 520,615 个碰撞三角面，用于地面跟随、墙体阻挡和校准拾取。
- 所有运行资源在本仓库中，无外部 CDN、跨站资源服务或业务后端。
- 浏览器需支持 WebGL 2 并开启硬件加速；首次加载速度取决于网络。
- 重建模型可能存在孔洞、采集噪声和未采集区域；可切换飞行越过障碍。

## 本地运行与验证

无需安装 npm 依赖。使用 Node.js 运行：

```sh
npm test
npm start
```

本机访问 http://localhost:8091/ancestral-home-walkthrough/ 。直接打开 `index.html` 会受到浏览器本地文件限制。

## GitHub Pages

Pages 的发布源为 `main` 分支根目录 `/`，`.nojekyll` 使静态文件原样发布。所有资源使用相对路径，可在仓库项目子目录正常加载。后续推送到 `main` 后自动发布。

PlayCanvas、Three.js 和 three-mesh-bvh 的许可证随文件保留在 `vendor/`。场景采集数据不因这些依赖的开源许可证而被另行授权。
